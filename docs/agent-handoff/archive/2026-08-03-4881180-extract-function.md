## Summary

Implemented a first safe editor refactoring that extracts a selected connected
value-flow subgraph into a normal Surface function and replaces the original
subgraph with one folded project Call. No Core semantics, runtime semantics, or
Project JSON schema version changed.

## User-Facing Changes

- Modifier-click can build an additive element selection.
- Empty-canvas marquee selects elements in the active container only.
- Dragging a multi-selection moves every selected element by the same delta and
  commits one undo/redo entry.
- The Inspector shows `Extract function` for element and element
  multi-selections when the planner can infer a safe signature.
- The Extract preview shows the inferred ordered parameters and result type.

## Design Decisions

- Selected elements are moved into the new function body and keep their element
  IDs. Internal selected wires keep their wire IDs. The source container gets a
  new folded `project_call` node and new cut-edge replacement wires.
- Incoming cut edges become ordinary function parameters, not captures.
- The new Surface function metadata in `surfaceFunctions`, the template
  container, and `surfaceProjectCalls` are materialized together by one command.
- The source container dependency list is updated to include the new template.
- The transformation is planned before mutation and applied through
  `extract_function` as one history transaction.

## Rejected Selection Shapes

The first safe slice rejects:

- managed resource-flow wires;
- `function`, `library_call`, and `project_call` nodes;
- disconnected selections;
- selections with no outgoing result or multiple outgoing results;
- selections with no incoming argument wire;
- cross-container selections;
- selected inputs that are not wired;
- implicit Product packing, captures, Copy, Drop, casts, or new Core nodes.
